# Private Notes

A private AI note assistant for UK counsellors and psychotherapists. The AI runs on the therapist's own device, so client information is never uploaded.

Status: early stage. This repo currently holds the waitlist page (`index.html`, served with GitHub Pages).

## Principles
- **Privacy first:** collect the least data possible, process on the device, no trackers, no selling data.
- **Honest:** no invented claims, stats or testimonials.
